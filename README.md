# Madrasa Tahfizul Quran – HTML Website Prototype

## Included
- Public website pages: Home, About, Academics, Admissions, Knowledge Centre, News & Events, Gallery, Donations, Branches, Contact, Privacy and Terms.
- Language selector for English, Urdu and Arabic with RTL direction switching and translated shared labels.
- Administrator prototype: Login, Dashboard, Website Content, Courses, Admission Enquiries, Donation Campaigns, Media Library and Users & Permissions.
- Shared CSS, JavaScript and SVG logo.

## Run locally
Open `index.html` in a browser, or run:
```bash
python -m http.server 8000
```
Then visit `http://localhost:8000`.

## Important
This is a static HTML/CSS/JavaScript front-end prototype. Forms and admin actions display demo feedback only. It does not include a database, backend APIs, secure authentication, persistent CMS, real uploads, admission processing, payment processing, approval enforcement or audit storage. Those must be implemented in the production application using the master prompt.

Institutional details used: Madrasa Tahfizul Quran; founder Abdul Bari Siddique; principal Abdul Wahid; established 1989; Muzaffarpur, Bihar; approximately 150 students; courses Hifz-ul-Quran, Nazira and Tajweed.

Missing contact details, biographies, course criteria, payment details and religious content are intentionally not fabricated.
